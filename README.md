# vibe_mail

Рассылка писем с индивидуальными вложениями по списку из YAML-конфига.
Один файл — `send_mail.py`, из зависимостей только PyYAML (уже есть в системе).

## Быстрый старт

```bash
cp config.example.yaml config.yaml
cp .env.example .env        # вписать SMTP_PASSWORD
mkdir -p attachments        # положить сюда файлы
python3 send_mail.py --dry-run
```

Пароль берётся из `SMTP_PASSWORD` в `.env` (переменная окружения имеет приоритет).
Для Gmail и Яндекса нужен **пароль приложения**, а не основной пароль от аккаунта.

## Конфиг

Формат целиком описан в `config.example.yaml`. Кратко: секция `smtp`, общие для всех
`subject` / `body` (и необязательный `body_html`), и список `recipients`, где у каждого
адреса свой набор `attachments` — пути относительно `attachments_dir`.

Относительные пути (`attachments_dir` и сам `sent.log`) резолвятся относительно
директории конфига, поэтому запускать удобнее всего из корня проекта.

## Флаги

| Флаг | Что делает |
|---|---|
| `--config PATH` | путь к конфигу (по умолчанию `config.yaml`) |
| `--dry-run` | показать, что будет отправлено; SMTP-соединение не открывается |
| `--delay N` | пауза между письмами в секундах (перекрывает конфиг) |
| `--log PATH` | журнал отправленных (по умолчанию `sent.log`) |
| `--no-resume` | не пропускать адреса, уже записанные в журнал |
| `--limit N` | отправить не больше N писем — удобно для боевого теста |
| `--only EMAIL` | отправить только одному адресу |
| `-v` | подробный лог, включая диалог с SMTP |

## Как это работает

1. **Валидация до отправки.** Проверяются адреса (синтаксис, дубликаты), наличие и
   читаемость каждого файла, суммарный размер вложений на письмо (лимит 25 МБ с учётом
   ~1.37× оверхеда base64). Если есть хоть одна проблема — печатается весь список и
   программа завершается, не отправив ничего.
2. **Возобновление.** Каждая успешная отправка сразу дописывается в `sent.log`
   (`время<TAB>email<TAB>OK`). Повторный запуск пропускает эти адреса, так что прерывание
   по Ctrl+C или сбой не приводят к дублям. Отключается флагом `--no-resume`.
3. **Ретраи.** Временные ошибки (4xx, обрыв соединения, таймаут) — до 3 попыток с паузой
   2/4/8 с и переподключением. Постоянные (5xx, отказ в получателе) — адрес помечается
   как failed, рассылка продолжается. В конце печатается сводка; код возврата 1, если
   были ошибки.

## Рекомендуемый порядок первой рассылки

```bash
python3 send_mail.py --dry-run          # сверить состав писем
python3 send_mail.py --limit 1          # одно письмо на свой адрес
python3 send_mail.py                    # остальные, уже отправленные пропустятся
```
